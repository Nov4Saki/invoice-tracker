# تطبيق إدارة وتتبع الفواتير والتقارير المالية | Invoice Tracker & Accounting App

تطبيق مكتبي متكامل وخفيف جداً لإدارة الفواتير والطلبات، ومتابعة الأرباح والخسائر، وسجل العملاء، والمخزون، مع دعم كامل للغتين العربية والإنجليزية والمظهرين الداكن والفاتح.

A lightweight, zero-dependency desktop application for small businesses to track orders, invoices, customer histories, inventory, and detailed financial reports (P&L, profit/loss, pie charts, histograms).

---

## المميزات الرئيسية | Key Features

1. **تتبع الفواتير والطلبات (Order & Invoice Tracking):**
   - إضافة وإدارة الفواتير مع تحديد هوامش الربح لكل صنف على حدة (سعر البيع مقابل سعر التكلفة).
   - إمكانية جدولة وتعديل الطلبات المستقبلية (Future Orders) بسهولة تامة في أي وقت قبل أو بعد تسليمها.
   - حالات الفواتير: مدفوعة (Paid)، معلقة (Pending)، مدفوعة جزئياً (Partial)، مسودة (Draft)، ملغاة (Cancelled).
   - تسجيل الدفعات الجزئية ومتابعة المتبقي غير المحصل (Outstanding Receivables).

2. **لوحة تحكم وتقارير مالية تفصيلية (Financial Dashboards & Reports):**
   - مؤشرات الأداء اللحظية (KPIs): إجمالي المبيعات، إجمالي التكلفة (COGS)، صافي الأرباح، هامش الربح %، المستحقات غير المحصلة.
   - **رسم بياني مدرج تكراري (Histogram / Bar Chart):** أداء شهري/أسبوعي تفاعلي يوضح الإيرادات وصافي الربح جنباً إلى جنب مع إمكانية التمرير لمعرفة التفاصيل.
   - **مخطط دائري (Donut / Pie Chart):** توزيع الأرباح مقابل التكاليف، وتوزيع حصص كبار العملاء.
   - تقرير قائمة الدخل والأرباح والخسائر (Profit & Loss / P&L Statement).
   - تقرير ربحية العملاء وترتيبهم حسب حجم المبيعات والأرباح المولدة.

3. **سجل وملف خاص لكل عميل (Customer Dashboards & Order History):**
   - صفحة خاصة لكل عميل توضح إجمالي مشترياته، أرباحك منه، رصيده المتبقي، ومدرج تكراري خاص به.
   - عرض السجل التاريخي الكامل لطلبات العميل مع إمكانية إضافة طلب جديد مخصص له بضغطة زر.

4. **صانع الفواتير وتصدير الصور وPDF (Invoice Maker):**
   - تصميم أنيق وعصري للفاتورة متوافق مع متطلبات الأعمال.
   - **تصدير كصورة عالية الدقة (PNG):** يتم توليد الصورة فورياً بنظام Canvas (2x Retina) لحفظها ومشاركتها مباشرة عبر واتساب أو البريد.
   - **تصدير إيصال حراري مصغر (Thermal Receipt Image):** صورة مناسبة لإيصالات الجوال والمحادثات.
   - **طباعة وحفظ بصيغة PDF:** متوافق مع طباعة A4 بدون أي زوائد أو هوامش متداخلة.

5. **البحث السريع اللحظي (Fast Real-time Search):**
   - اختصار مباشر `Ctrl + K` أو بالضغط على شريط البحث.
   - بحث فوري وسريع عبر اسم العميل، رقم الهاتف، البريد الإلكتروني، رقم الفاتورة، أو المنتجات.

6. **وضع إدارة المخزون الاختياري (Optional Inventory Mode):**
   - يمكن تفعيله أو تعطيله من صفحة الإعدادات (معطل افتراضياً كما طُلب).
   - عند التفعيل:
     - يتم ربط أصناف الفاتورة بالمخزون مباشرة وعرض الكمية المتوفرة لحظياً.
     - تنبيه فوري في حال تجاوزت الكمية المطلوبة الرصيد المتوفر في المخزن.
     - خصم المخزون تلقائياً عند حفظ الفاتورة وإعادته عند الإلغاء أو التعديل.
     - إدارة كاملة للمنتجات وزيادة الرصيد (Restock) وتنبيهات انخفاض الكميات.

7. **تصميم عصري ودعم اللغات والمظهر (/ui-ux-pro-max):**
   - تصميم سويسري مبسط وأنيق (Swiss Minimalist UI).
   - الوضع الداكن (Dark Mode) والوضع الفاتح (Light Mode).
   - واجهة كاملة باللغة العربية (RTL) وباللغة الإنجليزية (LTR) بنقرة زر واحدة.

8. **حجم تطبيق فائق الصغر وبدون أي مكتبات خارجية (Zero Dependencies):**
   - حجم المشروع بالكامل أقل من 400 كيلوبايت!
   - لا يحتاج لتثبيت أي مكتبة بواسطة `pip` (يعتمد فقط على مكتبات بايثون القياسية: `sqlite3`, `http.server`, `json`).
   - تشغيل لحظي (Startup time < 250ms).
   - يعمل كنافذة مكتبية أصلية أنيقة عبر وضع تطبيقات مايكروسوفت إيدج (Edge App Mode) المدمج في ويندوز 10 و 11.

## طريقة التشغيل | How to Run

### في نظام ويندوز (Windows):
1. **التشغيل المباشر للملف التنفيذي (Standalone Executable):**
   - قم بتشغيل الملف `dist/InvoiceTracker.exe` مباشرة بدون الحاجة لأي تثبيت أو بيئة بايثون!
2. **التشغيل الصامت بدون نافذة موجه الأوامر:**
   - انقر نقراً مزدوجاً على الملف `run_silent.vbs`.
3. **التشغيل عبر السكربت:**
   - انقر نقراً مزدوجاً على الملف `run.bat`.
4. **أو من موجه الأوامر (PowerShell / Command Prompt):**
```powershell
python main.py
```

التطبيق سيعمل فوراً ويفتح في نافذة مكتبية مستقلة بدون شريط متصفح وبدون أي تأخير!

## تشغيل الاختبارات الآلية | Running Automated Tests

يحتوي المشروع على حزمة اختبارات شاملة تغطي قاعدة البيانات، والعمليات الحسابية للأرباح والخسائر، وتتبع المخزون، والبحث السريع، والواجهة الخلفية:

```powershell
python tests/run_tests.py
```

## هيكلة المشروع | Project Structure

```

│   ├── db.py            # طبقة قاعدة البيانات SQLite والبيانات التجريبية الأولية
│   ├── server.py        # خادم REST API بدون أي مكتبات خارجية
│   ├── launcher.py      # مشغل النافذة المكتبية (Edge App Mode / Chrome / Webview)
│   └── static/
│       ├── index.html   # هيكل الواجهة المبسطة
│       ├── style.css    # نظام التصميم السويسري، الوضع الداكن/الفاتح، RTL/LTR
│       ├── app.js       # منطق التطبيق والتنقل والبحث وتعديل الفواتير
│       ├── charts.js    # محرك الرسوم البيانية التفاعلية (Pie & Histogram) بـ Canvas نقي
│       ├── invoice.js   # صانع الفواتير وتصدير صور PNG عالية الدقة وطباعة PDF
│       └── i18n.js      # قاموس الترجمة الكامل (عربي وإنجليزي)
├── tests/
│   ├── test_db.py       # اختبارات قاعدة البيانات وسلامة العمليات
│   ├── test_api.py      # اختبارات مسارات API وحسابات الخسارة والربح والمخزون
│   └── run_tests.py     # مشغل الاختبارات
├── run.bat              # مشغل فوري بنقرة واحدة لنظام ويندوز
├── run_silent.vbs       # تشغيل صامت بدون نافذة سوداء
├── main.py              # نقطة الدخول الرئيسية
└── README.md            # هذا الملف
```
